# Search identity foundation

The public page uses one canonical URL and keeps the person's name, mentoring purpose, and academic context in crawlable HTML. JSON-LD connects the visible person, service, and website entities without inventing credentials or review claims. A sitemap and robots file make the single-page deployment explicit to crawlers.

Search visibility still depends on discovery, indexing, relevance, and external reputation. Search Console verification and a URL inspection request are operational steps after deployment; structured data and metadata can help Google understand the page but cannot guarantee a ranking or rich result.
